## 🇬🇧

### Philosophy
**Waguriholic-GUI** is a lightweight, fan-made resource pack that replaces standard vanilla container interfaces (Inventory, Furnaces, Smoker, Brewing Stand, Creative Menu) with clean, pixel-art adaptations of **Kaoruko Waguri**.

* **Made for myself:** Crafted purely for personal enjoyment (so it turned out as best as it could :)).
* **Vibe:** Clean, minimalist, and **STRICTLY SFW**!
